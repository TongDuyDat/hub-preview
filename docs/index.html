How to Install

Install the VSIX, enable agent registration, then reconnect your agent. English guide · Hướng dẫn tiếng Việt

Option A

VS Code Installation

  1. Download the extension using the Download for VS Code button above.
  2. Open VS Code and press Ctrl+Shift+X (Extensions view).
  3. Click the ... (Views and More Actions) menu in the top-right corner.
  4. Select Install from VSIX... and choose the downloaded file (VS Code 1.103.0+).
  5. Reload that window if prompted, open your project and run Review Hub: Scan and Register Detected Agents.
Option B

JetBrains IDE Installation

  1. Download the plugin using the Download for JetBrains button above.
  2. Open your IDE (IntelliJ, WebStorm, PyCharm, etc.).
  3. Open Settings / Preferences (Ctrl+Alt+S or Cmd+,).
  4. Go to Plugins, click the ⚙️ gear icon, and select Install Plugin from Disk....
Option C

Configure Your AI Agent

  1. Enable Review Hub: Auto Register MCP and select your agents in Settings. An agent checkbox alone does not enable registration.
  2. Scan, inspect the results and reconnect MCP or start a new agent session. The VSIX already includes the MCP server.
  3. Run Review Hub: Install agent instructions, then ask your agent to submit edits through Hub proposal tools.

Frequently Asked Questions

Everything you need to know about Review Hub

🔒 Does Review Hub send my code to the cloud?

Review Hub stores changes, baselines and diffs locally. Your AI agent’s own settings govern what it sends to its model provider. This website fetches public release metadata from GitHub.

🤖 Which AI coding agents are supported?

Auto-registration supports Claude Code, Codex, Cursor, Windsurf, OpenCode, Cline, Roo Code, Gemini CLI, Antigravity, DeepSeek Harness and Oh My Pi. The VS Code extension reviews proposals submitted through Review Hub MCP; direct shell writes and Git diffs are not imported.

⚡ Can I use VS Code and JetBrains together?

Review Hub shares a local server across IDE windows. Use compatible builds on the same host; JetBrains releases have separate feature availability. After an update, inspect Show Hub Info and reload the hosting window if it still runs an older Hub.

🛡️ What if the AI refuses to call MCP?

Run Install agent instructions to guide agents to Hub. Optional Require Review hooks enforce tool routing for Claude Code and Oh My Pi on Linux/macOS. Other clients do not have equivalent hook enforcement. See the installation guide for setup and removal.
